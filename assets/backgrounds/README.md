# 배경음 WAV 교체

별도 파일 없이 실행하면 카페·역·거리·실내·군중을 표현하는 절차적 근사음을 만듭니다. 실제 장소에서 녹음한 음원이 아니며 장소의 실제 소음 수준을 재현하지 않습니다.

직접 녹음했거나 사용할 권한이 있는 WAV를 이 폴더 또는 별도 폴더에 넣으세요.

| 배경 | 파일명 |
| --- | --- |
| 카페 | `cafe.wav` |
| 역 | `station.wav` |
| 거리 | `street.wav` |
| 실내 | `room.wav` |
| 군중 | `crowd.wav` |

UI의 **배경 WAV 폴더** 또는 CLI의 `--background-dir assets/backgrounds`로 지정합니다. 파일명이 없는 배경은 절차적 근사음을 사용하며 실제 사용한 출처가 `metadata.csv`의 `background_source`에 기록됩니다. 스테레오 파일은 모노로 변환하고 음성의 샘플레이트로 리샘플링합니다.

음성이 시작되기 전과 끝난 뒤에 기본 0.5초씩 배경을 붙입니다. 배경은 페이드하고 발화 구간의 RMS를 기준으로 요청한 SNR에 맞춥니다. 짧은 배경 파일은 반복되므로 충분히 긴 녹음을 권장합니다.

음원을 저장소에 올리려면 재배포 조건도 확인하고 파일별 출처·제작자·라이선스를 함께 기록하세요. 기본 `.gitignore`는 이 폴더의 WAV를 제외합니다.
